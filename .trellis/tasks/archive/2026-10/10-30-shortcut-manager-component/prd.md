# PRD: 全局快捷键独立组件化与交互式帮助指南

## 1. 背景与目标

在桌面应用开发中，全局快捷键是高频核心功能。目前设置中心已支持主进程快捷键注册与冲突检测，但输入交互仍为手动文本录入，且缺少直观的帮助引导。
本项目旨在：

1. **完整组件化**：将快捷键录制、校验、展示、冲突反馈、重置恢复完整封装为独立的 Vue 3 业务组件 `GlobalShortcutManager.vue` 及底层按键拾取器 `ShortcutRecorder.vue`。
2. **直观交互**：提供“按键录制”模式，用户聚焦后直接敲击键盘实体按键即可自动捕获并格式化为标准 Accelerator 字符串。
3. **完善的帮助指引**：在组件内集成交互式帮助信息（支持 Tooltip / 抽屉 / 折叠指南），包含 Mac/Windows 键位对照、冲突排查手册（如微信截图、系统聚焦快捷键占用）及合法修饰键规则说明。

## 2. 核心功能需求

- **FR-1 按键录制 (ShortcutRecorder)**:
  - 监听原生 `keydown` 事件，阻止浏览器默认行为；
  - 自动识别 `Ctrl` / `Cmd` / `Alt` / `Shift` 修饰键以及常规字母/数字/功能键（F1-F12）；
  - 支持修饰键输入中的过渡状态显示（“正在录入组合键...”）；
  - 单字母/单修饰键非法拦截提示，强制要求至少一个修饰键以保护系统正常输入；
  - 支持 `Escape` 取消录制，支持 `Backspace` / `Delete` 清除。
- **FR-2 全局快捷键管理组件 (GlobalShortcutManager)**:
  - 统一承载功能说明、录制器、状态徽章、重置按钮以及帮助提示；
  - 与主进程 IPC `shortcut:register` 实时联动：当主进程检测到冲突时，提供醒目的红色冲突警告与回滚机制；
  - 支持跨平台按键符号呈现（macOS 呈现 `⌘ / ⌥ / ⇧`，Windows/Linux 呈现 `Ctrl / Alt / Shift`）。
- **FR-3 快捷键帮助信息 (ShortcutHelpGuide)**:
  - 平台键位对照表（CommandOrControl 在双端的映射）；
  - 常见快捷键冲突排障说明（解释为何无法识别外部冲突进程、常见被占用的按键组合建议）；
  - 支持点击快速预设（如推荐安全组合：`Ctrl+Shift+X`、`Ctrl+Alt+K` 等）。
- **FR-4 国际化与响应式**:
  - 完善中英文语言包（`zh-CN` / `en-US`）；
  - 适配深色/浅色主题。

## 3. 验收标准

1. 组件代码符合单包结构与单一职责原则，不引入非必要的第三方重型库。
2. 通过全量单测覆盖按键解析、格式化及规则拦截逻辑。
3. `pnpm check` 0 错误，`vue-tsc` 0 错误，测试套件 100% 通过。
