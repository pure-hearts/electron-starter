# Commercial Settings Center & Advanced Desktop Features

## Goal

为 `electron-starter` 打造一套商业级现代化**设置中心（Settings Center）**与**高级桌面特有能力**，将底层核心能力（通知联动、下载跨重启持久化、系统托盘、Shell 诊断、全局快捷键、离线感知）在统一且美观的 UI 上完整呈现与交互闭环，让模板具备直接支撑大型商业客户端的基础设施与展示窗口。

## Requirements

### 1. 商业化设置中心 (Settings Center UI & Router)

- **UI 架构与设计**：
  - 基于 Naive UI 打造专业、科技感的多标签页设置面板（页面路由 `/settings` 或全局模态呼出）。
  - 分类清晰的侧边/分栏导航：
    - 🌐 **常规设置 (General)**：语言偏好（中/英文）、外观主题（跟随系统 / 深色 / 浅色）、关闭主窗口动作（最小化到托盘 vs 退出程序）、开机自启动开关。
    - 📥 **下载偏好 (Downloads)**：默认下载目录设置（带文件夹选择器 `dialog:showOpenDialog`）、最大并发下载数滑块（1~50）、跨重启未完成任务自动恢复开关。
    - 🔔 **通知偏好 (Notifications)**：系统通知总开关、下载完成/失败通知联动、更新就绪通知联动、通知测试按钮。
    - ⌨️ **全局快捷键 (Shortcuts)**：自定义主窗口呼出/隐藏全局快捷键录制组件、冲突校验与重置。
    - 🛠️ **系统诊断 (Diagnostics)**：网络连接状态指示器、系统环境参数、脱敏日志一键打包导出（`.zip`）。
    - ℹ️ **关于与更新 (About)**：当前版本、构建时间、检查更新按钮、GitHub 仓库与许可证。

### 2. 系统通知与核心业务链路深度联动

- **下载任务完成/失败通知**：下载成功后自动弹出桌面系统通知，点击通知直接在系统文件管理器中定位该文件（调用 `shell:showItemInFolder`）。
- **更新就绪业务通知**：全包安装包或热更新解压就绪后，提示“新版本已准备就绪，点击重启应用即可生效”，避免静默重启或无感知。
- **通知配置持久化**：通知开关与偏好持久化至 `electron-store`，支持勿扰与各事件分类静音。

### 3. 下载管理器跨重启持久化 (Download Persistence & Auto-Resume)

- **任务状态持久化**：未完成（排队中、下载中、已暂停）的任务元数据保存至本地存储。
- **跨重启断点续传**：应用冷启动时检测未完成任务，支持在 UI 上展示“已恢复未完成任务”并支持一键继续下载。
- **动态路径配置**：下载时优先采用设置中心指定的默认下载目录。

### 4. 系统诊断与日志一键导出 (Log Diagnostics)

- **日志诊断压缩**：主进程收集最近 7 天脱敏应用日志、系统与硬件信息（OS、Node、Electron、架构），利用已有的 `fflate` 纯前端/主进程安全压缩为 ZIP 文件。
- **导出对话框**：弹窗让用户保存为 `diagnostic-logs-<timestamp>.zip`，方便故障排查。

### 5. 全局快捷键管理器 (Global Shortcuts)

- **快捷键注册与注销**：主进程安全管理 `globalShortcut`，窗口隐藏时按快捷键立即呼出并聚焦主窗口；避免快捷键冲突。
- **快捷键录制器**：设置界面提供按键监听与格式化录制组件。

### 6. 全局网络状态与离线感知 (Network Connectivity)

- **原生状态监听**：主进程结合 Electron `net.isOnline()` 与渲染层 `navigator.onLine`，提供统一的在线状态广播。
- **UI 状态感知**：当网络断开时，UI 顶部浮现无干扰提示条并自动暂停新网络请求，恢复后自动提示。

## Acceptance Criteria

- [x] **设置中心页面**：创建 `src/renderer/views/Settings.vue` 及对应子组件，接入 Vue Router `/settings`，并在顶部导航栏、TitleBar 和托盘菜单中增加“设置”入口。
- [x] **配置双向绑定与持久化**：设置中心所有选项（常规、下载、通知、快捷键）均通过类型化 IPC 与 `electron-store` 双向同步并持久化（schemaVersion=2）。
- [x] **下载通知与文件定位**：下载完成触发通知中心弹窗，点击通知能在原生资源管理器定位已下载文件（`shell.showItemInFolder`）。
- [x] **下载偏好联动**：默认下载目录设置与自定义选择文件夹弹窗生效，并发动态调节。
- [x] **日志导出功能**：点击【打包并导出诊断日志】能成功打包并弹出保存对话框生成脱敏日志 ZIP（经由 fflate 压缩）。
- [x] **全局快捷键**：成功注册自定义快捷键（默认 `CommandOrControl+Shift+X`），在应用失焦或隐藏到托盘时可一键呼出主窗口。
- [x] **全局网络感知**：提供 `NetworkBanner.vue` 离线感知与广播，WebShim 降级对齐。
- [x] **自动化测试覆盖**：新增各能力的独立单元/集成测试套件，全量 41 套件 154 项测试用例 100% 通过，并通过 `vp check` 与 `vue-tsc`。

## Non-Goals & Out of Scope

- 不引入外部商业分析与追踪平台（如 Google Analytics、Bugsnag 等），诊断信息仅保留在本地。
- 绝不引入破坏 Electron 沙箱或 CSP 的危险原生模块。
